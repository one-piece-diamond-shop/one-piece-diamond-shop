فروشگاه آزمایشی الماس One Piece Legends
=======================================

این بسته فقط نمونه اولیه است؛ درگاه بانکی و تتر واقعی ندارد و هیچ پولی دریافت نمی‌کند.

اجرا روی کامپیوتر/سرور آزمایشی:
1) Python و Flask را نصب کنید:
   pip install flask requests
2) متغیرهای امنیتی را تنظیم کنید:
   SHOP_API_KEY و SHOP_ADMIN_KEY را به رشته‌های طولانی و تصادفی تغییر دهید.
   در محیط عمومی SHOP_ENV را روی production قرار دهید.
3) اجرا:
   python app.py
4) سایت روی پورت 5000 بالا می‌آید.

نکات مهم:
- در نسخه development مسیر تأیید آزمایشی فعال است؛ آن را روی سایت عمومی باز نگذارید.
- مبلغ‌ها و بسته‌ها در ابتدای app.py صرفاً نمونه‌اند و باید تأیید شوند.
- bot_bridge_example.py فقط نمونه است و هنوز به حلقه اصلی ربات متصل نشده.
- قبل از تغییر دیتابیس بازی، از one_piece_legends.db نسخه پشتیبان بگیرید.
- دیتابیس بازی را در اینترنت منتشر نکنید.
- پرداخت واقعی باید از طریق callback معتبر درگاه انجام شود؛ تصویر رسید یا پیام کاربر تأیید پرداخت نیست.
- برای حساب درگاه/پرداخت واقعی، مالکیت و مدیریت باید با یک بزرگسال واجد شرایط باشد.
